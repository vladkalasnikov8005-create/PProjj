# Интернет-магазин: товары и категории

В проекте реализованы модели каталога интернет-магазина:

- `Product` хранит название, описание и количество; приватная цена доступна через свойство `price`.
- Цена должна быть положительной. При попытке уменьшить её требуется подтвердить действие ответом `y`.
- `Product.new_product()` создаёт товар из словаря. Если передан список существующих товаров, совпадающий по имени товар объединяется: количество суммируется, а цена выбирается максимальная.
- `Category` хранит товары в приватном списке, добавляет их методом `add_product()` и предоставляет форматированную строку через свойство `products`.
- Счётчики `Category.category_count` и `Category.product_count` обновляются автоматически.

Запустить пример можно из корня проекта:

```bash
python main.py
```

Тесты и отчёт покрытия:

```bash
pytest --cov=src --cov-report=term-missing --cov-report=html
```

HTML-отчёт создаётся в `htmlcov/index.html`; эта сгенерированная директория не включается в Git. Краткий отчёт покрытия хранится в `coverage-report.txt`.
