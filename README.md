# Интернет-магазин: товары и категории

В проекте реализованы базовые модели каталога интернет-магазина:

- `Product` хранит название, описание, цену и количество товара.
- `Category` хранит название, описание и список объектов `Product`.
- Классовые счётчики `Category.category_count` и `Category.product_count` автоматически учитывают созданные категории и товары.

Запустить пример можно из корня проекта командой:

```bash
python main.py
```

Тесты и отчёт покрытия:

```bash
pytest --cov=src --cov-report=term-missing --cov-report=html
```

HTML-отчёт будет создан в `htmlcov/index.html` (директория `htmlcov` не включается в Git).
